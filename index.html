အထူးခြားဆုံး နေ့ရက် ✨

31.7.2007 ဆိုတဲ့ ဒီနေ့ရက်မှာ လောကကြီးထဲကို ရောက်ရှိလာခဲ့တဲ့ နှင်းအိလှိုင်အတွက် အမှတ်တရ မွေးနေ့လေး စတင်ပါပြီ။

Memory 01 / 15

၁၉ နှစ်ပြည့် မွေးနေ့မင်္ဂလာပါ 🩵

အသက် ၁၉ နှစ်ပြည့်သွားတဲ့ နှင်းအိလှိုင်ရေ... ဘဝခရီးလမ်းမှာ အမြဲတမ်း ပျော်ရွှင်မှုတွေနဲ့သာ လမ်းခင်းနိုင်ပါစေလို့ ဆုတောင်းပေးပါတယ်။

Memory 02 / 15

အပြုံးမပျက်ပါနဲ့ ✨

မင်းရဲ့ မျက်နှာပေါ်က အပြုံးလေးတွေက ဘေးနားကလူတွေကို အမြဲတမ်း အားဖြစ်စေပါတယ်။ အဲ့ဒီအပြုံးလေးတွေ အမြဲတမ်း တောက်ပနေပါစေ။

Memory 03 / 15

အိပ်မက်များဆီသို့ 🌟

ကိုယ့်ရဲ့ ရည်မှန်းချက်နဲ့ အိပ်မက်တွေကို တစိုက်မတ်မတ် လျှောက်လှမ်းပြီး အောင်မြင်မှု ပန်းတိုင်ကို အရောက်လှမ်းနိုင်ပါစေ။

Memory 04 / 15

Friendship အမှတ်တရ 🤝

၁၂.၅.၂၀၂၅ ကတည်းက စတင်ခဲ့တဲ့ တို့တွေရဲ့ ခင်မင်မှုက တကယ့်ကို တန်ဖိုးရှိပြီး ထာဝရ တည်တံ့နေမှာပါ။

Memory 05 / 15

တန်ဖိုးရှိလှတဲ့ ခင်မင်မှု 🩵

ငါတို့နှစ်ယောက် ရန်ဖြစ်လို့ သံယောဇဉ်ပြတ်မလိုတောင် ဖြစ်ခဲ့ကြသေးတယ်နော်... ဒါပေမဲ့ မင်းဘက်က အရင်စခေါ်ပေးလို့ ပြန်အဆင်ပြေသွားခဲ့တာ။ အဲ့ဒီအတွက် အများကြီး ကျေးဇူးတင်သလို အရမ်းလည်း တန်ဖိုးထားပါတယ်!

Memory 06 / 15

ခွန်အားတွေနဲ့ ရှေ့ဆက် 💫

အခက်အခဲ ဘယ်လောက်ပဲရှိရှိ ကြံ့ကြံ့ခံပြီး ကျော်ဖြတ်နိုင်တဲ့ သတ္တိတွေ မင်းမှာ အပြည့်အဝ ရှိပါတယ်။

Memory 07 / 15

တောက်ပတဲ့ ကြယ်တစ်ပွင့် 🎈

ဘယ်နေရာရောက်ရောက် ကိုယ့်အရည်အချင်းနဲ့ကိုယ် ထင်းလင်းပေါ်လွင်နေတဲ့ ကြယ်လေးတစ်ပွင့် ဖြစ်ပါစေ။

Memory 08 / 15

အေးချမ်းသည့်ဘဝ 🤍

စိတ်ရှုပ်စရာတွေကင်းဝေးပြီး စိတ်အေးချမ်းသာနဲ့ ဘဝကို လှပစွာ ဖြတ်သန်းနိုင်ပါစေ။

Memory 09 / 15

ရယ်မောခြင်းများစွာ 🌸

မျက်ရည်ကျစရာတွေထက် ရယ်မောပျော်ရွှင်ရမယ့် အချိန်တွေကသာ မင်းရဲ့ဘဝမှာ ပိုများပါစေ။

Memory 10 / 15

ကိုယ်ချင်းစာတရား 🍀

စိတ်ထားဖြူစင်ပြီး သူတစ်ပါးအပေါ် ကူညီတတ်တဲ့ မင်းရဲ့ စိတ်ရင်းလေးကို အမြဲတမ်း ထိန်းသိမ်းထားပါ။

Memory 11 / 15

ကျန်းမာရွှင်လန်းပါစေ 🌿

စိတ်ရော ကိုယ်ပါ ကျန်းမာပြီး နေ့ရက်တိုင်းမှာ လန်းဆန်းတက်ကြွစွာနဲ့ လိုရာခရီးကို လျှောက်လှမ်းနိုင်ပါစေ။

Memory 12 / 15

နားလည်မှုများစွာဖြင့် 🤍

အမြဲတမ်း နားလည်ပေးနိုင်တဲ့ သူငယ်ချင်းကောင်းတစ်ယောက် ဖြစ်ပေးခဲ့လို့လည်း ကျေးဇူးအများကြီး တင်ပါတယ်နော်။

Memory 13 / 15

လုပ်ကိုင်သမျှ စီးပွားရေးနဲ့ ပညာရေး၊ ဘဝရဲ့ ကဏ္ဍတိုင်းမှာ ထိပ်ဆုံးက အောင်မြင်သူဖြစ်ပါစေ။

Memory 14 / 15

ချစ်ခြင်းများစွာဖြင့် 🎁

🎉 HAPPY 19th BIRTHDAY! 🎉

" နှင်းအိလှိုင် " 🩵

အသက် ၁၉ နှစ်ပြည့်သွားတဲ့ အမှတ်တရ မွေးနေ့လေးမှာ စိတ်၏ချမ်းသာခြင်း၊ ကိုယ်၏ကျန်းမာခြင်းတို့နဲ့ ပြည့်စုံပြီး လိုအင်ဆန္ဒမှန်သမျှ အကုန်ပြည့်ဝပါစေလို့ ဆုတောင်းပေးပါတယ်။

31.7.2007 မှာ မွေးဖွားခဲ့တဲ့ မင်းလေးဟာ ငါတို့အတွက်တော့ အမြဲတမ်း ခင်ဖို့ကောင်းပြီး တန်ဖိုးရှိတဲ့ သူငယ်ချင်းတစ်ယောက်ပါ။ ၁၂.၅.၂၀၂၅ ကတည်းက စတင်ခဲ့တဲ့ တို့တွေရဲ့ ခင်မင်မှုလေးမှာ ရန်ဖြစ်လို့ သံယောဇဉ်ပြတ်မလိုတောင် ဖြစ်ခဲ့ကြပေမဲ့ မင်းဘက်က အရင်စခေါ်ပေးလို့ အရာရာ ပြန်အဆင်ပြေသွားခဲ့တဲ့ အမှတ်တရလေးကိုလည်း အမြဲတမ်း တန်ဖိုးထားသတိရနေမှာပါ။

ရှေ့ဆက်ရမယ့် ဘဝခရီးလမ်းမှာလည်း အခက်အခဲမှန်သမျှကို ရဲရဲဝံ့ဝံ့ ကျော်ဖြတ်နိုင်ပြီး ကိုယ်မှန်းမျှော်ထားတဲ့ အိပ်မက်တွေ၊ အောင်မြင်မှုတွေကို အရယူနိုင်ပါစေ။ မျက်နှာပေါ်မှာလည်း အပြုံးလေးတွေ အမြဲတမ်း ပိုင်ဆိုင်နိုင်ပါစေ။

ထာဝရ ပျော်ရွှင်ပါစေ သူငယ်ချင်းလေး... 🎁🩵
